# Don't Lose It

An AI-powered personal-item guardian and scrapbook for iPhone.

Users photograph the belongings they have spread out at a library or café,
turn them into personal stickers, and start a guard session. When they leave,
the app reminds them to confirm that everything has returned with them.

## Project status

The product definition and MVP PRD are complete. The next phase is low-fidelity
flow design, technical spikes for object cutouts and background departure
detection, and a high-fidelity Figma prototype.
