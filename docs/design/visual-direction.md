# 复古手账拼贴视觉方向

记录日期：2026-11-02（Asia/Shanghai）。

用户已提供 Traveler's Notebook 风格参考照片并选择该方向。参考材料只用于提炼纸张、拼贴、胶带、印章、手写和低饱和色彩特征，不直接复制其中的照片、插画或其他素材。本页是待高保真样页和用户测试验证的 `draft`，不是最终品牌规范。

## 视觉原则

- 以真实物品抠图和白边贴纸作为主要视觉资产，不做通用卡通游戏。
- 使用暖白纸张、淡网格、牛皮纸、和纸胶带、票根、邮戳、印章和手写注释建立收藏感。
- 采用有意的错落和层次，避免无规则堆叠导致信息无法扫读。
- 遵守“日常浏览浓手账、关键核对轻手账”：手账与分享页丰富，核对与权限页克制。
- 装饰不遮挡操作，不依赖颜色单独表达状态，不牺牲大字体、对比度和触控目标。

## 初始设计 tokens

| 类别 | 初始值 | 用途 |
|---|---|---|
| 纸张底色 | `#F4EBDD` | 页面与手账纸 |
| 浅纸色 | `#FFF9EE` | 清单、输入与高对比内容 |
| 主文字 | `#2D2925` | 标题和正文 |
| 次文字 | `#6F675D` | 辅助说明 |
| 海军蓝 | `#24485A` | 主操作、印章、重点标签 |
| 橄榄绿 | `#687158` | 守护状态与成功反馈 |
| 酒红 | `#87464A` | 重要物品与克制的强调 |
| 牛皮纸 | `#C8A677` | 拼贴层和票根 |
| 和纸胶带 | `#D8C6A5` | 半透明装饰，不承载正文 |

正文使用系统无衬线字体，标题可使用衬线字体，手写只用于短标签和装饰性注释。实际字体、字号层级和动效时长仍需样页评审。

## 三种首页构图

- A「自由拼贴」：不对称贴纸、胶带和便签围绕唯一主操作，验证收藏感。
- B「杂志网格」：清晰的编辑式网格和较多留白，验证信息层级与可读性。
- C「摊开手账」：左右分栏的笔记本构图，验证日期、物品与主操作的空间关系。

三种构图只用于视觉探索，不改变已经确认的今日手账入口、主导航和守护流程。

## 样页范围

1. 今日手账：完整呈现纸张、拼贴、物品贴纸、日期、胶带、印章和主操作。
2. 当前守护：以较轻的拼贴呈现守护点、时间、物品和主动核对入口。
3. 离场核对：使用浅纸色和高对比清单，普通物品批量确认，重要物品逐件确认。

样页使用合成物品和虚构地点，不接真实相机、AI、定位、权限或持久化数据。交付物是一次性视觉原型，不是生产 UI，也不代表低保真可用性门槛已通过。

## 运行

在仓库根目录执行：

```powershell
python -m http.server 4174 --directory docs/design/visual-direction-prototype
```

打开 `http://localhost:4174/?variant=A`。顶部切换三张样页，底部箭头或键盘左右键切换首页 A/B/C 构图。

## 评审证据

需要检查：

- 用户是否认为页面具有愿意保存和分享的手账感。
- 主操作是否仍然第一眼可见。
- 贴纸、胶带和纸张层次是否造成误点或阅读困难。
- 当前守护和完整核对能否在移动中快速扫读。
- 大字体、读屏顺序、对比度和 Reduce Motion 是否保留所有信息与操作。

视觉样页通过后才进入完整高保真 Figma 和五名学生测试；未通过时只修订视觉系统，不改写已验证的产品规则。
