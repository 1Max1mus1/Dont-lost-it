# 低保真页面与状态清单

整理日期：2026-10-29（Asia/Shanghai）。

本清单把[用户流程](user-flows.md)和[原型计划](prototype-plan.md)转换为可制作的页面状态。它只验证顺序、层级、文案和恢复路径，不选择最终视觉风格，也不代表真实相机、AI、定位或系统权限已经实现。

## 运行可点击原型

在仓库根目录执行：

```powershell
python -m http.server 4173 --directory docs/design/low-fidelity-prototype
```

打开 `http://localhost:4173/`。首页提供 `?variant=A`、`?variant=B`、`?variant=C` 三种信息层级方案；浮层左右按钮或键盘方向键可切换。原型代码是一次性设计材料，不是生产应用。

## 页面清单

| ID | 页面或状态 | 必须可见的信息与操作 | 恢复或出口 |
|---|---|---|---|
| LF-01 | 空白今日手账 | 一句用途说明、主操作“剪下今天带来的东西”、次操作“从已有物品开始”、手账/物品栏导航 | 无需权限即可浏览物品栏 |
| LF-02 | 草稿恢复 | “继续整理”“丢弃”，明确草稿尚未开始守护 | 丢弃需确认；可返回保留草稿 |

| LF-04 | 已有物品与包包模板 | 具体物品、模板默认不勾选、全选、本次已选数量 | 可返回首页；不强制选模板 |
| LF-05 | 拍照引导 | 摊开物品、保持完整入镜的提示和模拟拍摄按钮 | 返回首页；可改用手动添加 |
| LF-06 | 识别处理中 | 正在识别轮廓，保留原照片上下文 | 可取消并回到拍照引导 |

| LF-08 | 识别失败 | 诚实失败说明、“重试”“手动添加物品并开始守护” | 两条路径都不阻塞任务 |

| LF-10 | 剪贴与贴纸摞 | 点选即加入、连续点选不阻塞、一键剪下全部、贴纸数量 | 可取消选择；确认前仍可补充 |
| LF-11 | 身份不明确 | 相似候选、“这是新物品吗”、当前选择 | 可更改关联，不错误合并物品 |
| LF-12 | 清单集中确认 | 可编辑名称、重要开关、身份状态、未入镜补充提示 | 返回剪贴；添加物品；纠正身份 |

| LF-14 | 模拟系统权限 | 定位与通知的允许/拒绝选择 | 拒绝后明确降级，不假装提醒已开启 |
| LF-15 | 自动守护中 | 守护点、已开始时间、完整物品、自动提醒状态 | 主动核对、暂离、补充物品 |

| LF-20 | 暂离暂停与到期 | 提醒已暂停、到期一次中性提示、延长、开始核对、“我回来了” | 未回应继续暂停；返回后恢复 |
| LF-21 | 完整离场核对 | 全部物品、普通物品批量确认、重要物品逐件确认 | 每件可改为还没找到；可返回守护 |
| LF-22 | 重要物品追加提醒 | 更直接的文案、仍未确认的重要物品、仅追加一次 | 打开完整清单，不无限提醒 |
| LF-23 | 全员归队 | 完成结果和专属印章 | 查看今日手账 |
| LF-24 | 最近出现与寻找中 | 贴纸或名称、原图区域高亮、地点时间、近期记录 | “找到了”返回核对；“暂时找不到”进入结束确认 |
| LF-25 | 保留待找回并结束 | 不盖全员归队、独立记录、局部照片保留说明 | 可继续寻找或明确结束；结束后允许新守护 |
| LF-26 | 后续找回 | “找回啦”、实际找回日期、原始离场结果保留 | 查看历史；局部证据默认删除 |
| LF-27 | 每日手账与历史 | 同日多任务卡、全员归队/待找回/已找回状态、累计记录 | 对待找回记录执行找回；进入分享 |
| LF-28 | 分享预览 | 默认带入物品、点选隐藏、地点时间与重要标记默认隐藏 | 返回手账；必须确认最终预览 |
| LF-29 | 导出结果 | 与预览一致的竖版卡片和模拟导出反馈 | 返回编辑或完成 |

## 关键状态矩阵

| 维度 | 需要覆盖的状态 |
|---|---|
| 首页 | 首次空白、已有草稿、守护中、当日已有历史卡 |
| 图像处理 | 未拍摄、处理中、成功、漏识别、失败、手动名称回退 |
| 物品身份 | 高置信已有、多个候选、新物品、纠正错误关联 |
| 权限 | 未询问、自动提醒已开启、定位或通知拒绝、手动模式 |
| 当前任务 | 草稿、守护中、暂离、待核对、寻找中、已完成 |
| 暂离 | 时长选择、暂停中、到期一次提示、延长、返回恢复 |
| 核对 | 普通批量、普通逐件、重要逐件、全部带齐、仍有待找回 |
| 找回 | 有照片证据、名称-only 无证据、核对期间找到、结束后找回 |
| 手账与分享 | 多任务、原始结果保留、后续找回日期、物品隐藏、最终预览 |

## 原型验收路径

1. 首次用户不经过独立引导页，从今日手账完成拍照、剪贴、身份确认和手动守护。
2. 从识别失败重试，或用手写名称继续，不产生虚假照片证据。
3. 纠正一个相似物品身份，添加未入镜物品，并设置重要物品。
4. 拒绝自动提醒权限后仍能开始守护，再主动进入完整核对。
5. 从离场提醒选择暂离，延长或返回；到期未回应不会恢复报警。
6. 普通物品批量确认，重要物品逐件确认，获得“全员归队”。
7. 标记物品未找到，查看最近出现，保留独立待找回并在之后标记“找回啦”。
8. 查看同日多张手账卡，隐藏一件物品并完成隐私安全分享预览。

以上路径可点击不等于可用性门槛已通过；仍需新用户在没有口头指导的情况下完成测试。任何视觉方向、真实系统能力和技术栈选择均不在本低保真交付物中决定。
